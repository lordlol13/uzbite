# Работа с Excel (`.xlsx`) и CSV (`.csv`)

## 1. Поддерживаемые операции

1. **Шаблон меню** (`GET /api/restaurant-account/imports/template?format=xlsx|csv`)
   - Содержит правильные заголовки (`Артикул`, `Название`, `Описание`, `Категория`, `Цена`, `Доступность`), примеры строк и лист `Инструкция` в `.xlsx` со схемой версии `uzbite-menu-v1`.
2. **Импорт меню и массовое обновление цен** (`POST /api/restaurant-account/imports/preview` → `POST /api/restaurant-account/imports/:jobId/confirm`)
   - Перед сохранением всегда формируется таблица предпросмотра (`ImportJob` + `ImportJobRowError`).
   - Показывается старая и новая цена, статус строки (`READY_ADD`, `READY_UPDATE`, `SKIPPED`, `CONFLICT`, `ERROR`) и ошибки с точными номерами строк.
   - Совпадения определяются по `ID` или `Артикулу (SKU)` (и по точному названию при отсутствии SKU) только внутри текущего ресторана.
   - Отсутствующие в файле блюда не удаляются; уже оформленные заказы сохраняют исторические `OrderItem.unitPrice`.
   - Повторное подтверждение уже выполненного `jobId` блокируется (`409 IMPORT_ALREADY_PROCESSED`).
   - Можно скачать отчёт об ошибках (`GET /api/restaurant-account/imports/:jobId/errors-export?format=xlsx|csv`).
3. **Экспорт меню** (`GET /api/restaurant-account/exports/menu?format=xlsx|csv&categoryId=&availability=`)
   - Фильтры: все, по категории, только доступные, только недоступные.
4. **Экспорт заказов** (`GET /api/restaurant-account/exports/orders?format=xlsx|csv&...`)
   - Фильтры по датам, статусу, способу оплаты и типу доставки.
   - Персональные контакты покупателей (телефон, адрес) **исключены по умолчанию** (`includeContacts=false`) и включаются только явным выбором операционного отчёта.
5. **Экспорт статистики** (`GET /api/restaurant-account/exports/statistics?format=xlsx|csv&from=&to=`)
   - Многолистовой `.xlsx` (`Сводка`, `Популярные блюда`, `Категории`) или `.csv` по реальным данным PostgreSQL.

## 2. Меры безопасности

- Проверка расширения **и** реальных сигнатур файла (`PK\x03\x04` для `.xlsx`; запрет макросов `.xlsm`/`.xlsb`, проверка валидного UTF-8 для `.csv`).
- Ограничение размера (5 МБ), строк (5 000) и столбцов (30).
- Защита от CSV/Spreadsheet Formula Injection:
  - При импорте формульные ячейки Excel и опасные префиксы `=`, `+`, `-`, `@`, `\t`, `\r` отклоняются с кодом `FORMULA_INJECTION`.
  - При экспорте опасные строковые значения экранируются префиксом `'`.
- Для CSV используется UTF-8 с BOM (`\uFEFF`) и поддержка запятой и точки с запятой для корректного открытия русских и узбекских символов в Excel на Windows.
